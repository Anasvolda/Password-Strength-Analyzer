# Password-Strength-Analyzer
Description: My first python project that I've made and ill only continue to improve from here on out. 

A simple python program that checks if you're password is strong or weak. 

## How to Use 

1. Run the program: 'python Password\ Strength\ Analyzer.py'
2. Enter your password
3. See if it's Strong, Medium, or Weak

## Features 
- Checks password length
- Checks for uppercase letters
- Checks for numbers
- Gives feedback
